# Internship Result Management System 
**Module:** COMP1044 | **Group:** G41

---

## Project Overview
The **Internship Result Management System** is a sophisticated web-based solution engineered to optimize the efficiency, transparency, and precision of student evaluations during industrial placements. By migrating from manual spreadsheet-based tracking to a secure, role-based digital architecture, the system facilitates a seamless workflow for both **Administrators** and **Faculty Assessors**.

### Core Functionalities
* **User Administration:** Full-lifecycle management (CRUD) for student profiles and Assessor accounts.
* **Internship Coordination:** Formal assignment of students to Assessors and centralized corporate host management.
* **Automated Assessment Engine:** Algorithmic grade calculation based on fixed weightages to eliminate human error.
* **Advanced Data Retrieval:** Intuitive search and filtering by Name or Unique ID.

* **Frontend:** HTML5, CSS3, JavaScript (Responsive User Interface)
